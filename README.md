          <li><strong>Deploy to Vercel:</strong> Link your forked repository to Vercel. Make sure to set your <code>GITHUB_TOKEN</code> environment variable so the GraphQL stats generator can authenticate.</li>
          <li><strong>Swap the Endpoints:</strong> Copy the code from this profile's <code>README.md</code>, and replace <code>https://hazy-readme-cards.vercel.app</code> with your unique Vercel production URL.</li>
        </ol>
